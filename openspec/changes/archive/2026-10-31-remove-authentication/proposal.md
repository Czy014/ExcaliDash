# remove-authentication

## Why

ExcaliDash 当前只作为 keeper 上的单用户绘图库运行。登录、注册、OIDC、密码找回、API key、管理员和用户切换会让前端与后端维护一整套没有使用者的认证路径，也让单用户页面继续暴露账户入口。

## What changes

- 删除前端认证页面、认证上下文、账户安全、管理员和 API key 入口。
- 删除后端 `/auth/*` 认证路由、OIDC、密码、令牌、API key 和管理员处理；绘图 API 继续通过固定的单用户身份取得数据边界。
- `AUTH_MODE` 固定为 `disabled` 的运行方式；旧数据库中的用户及认证字段保留，避免迁移时丢失绘图数据。
- 保留 CSRF、请求来源校验、公开链接分享、绘图版本检查、历史和文件保护。
- 偏好设置改为浏览器本地存储，不再依赖账户接口。

## Out of scope

- 不删除 Prisma 中已有用户、认证、分享和审计表，也不执行生产数据迁移。
- 不改变公开链接的读取和编辑策略。
- 不改变绘图、集合、文件、历史、导入导出和备份行为。
